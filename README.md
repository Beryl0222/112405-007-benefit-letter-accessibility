# 公共补助决定书的易读改写与权利保真

把社区服务机构的补助决定书改写成申请人读得懂的说明，同时让复核人员确认
**资格结论、金额、期限、例外与救济方式**仍与正式文本一致。所有内容仅使用
Python 标准库实现（Python 3.11+），可离线运行；演练决定书均为合成文本，
不对应真实人员、机构、地点或业务决定。

## 要解决的问题

1. 「可在十日内补交」容易被误读成**已经获批**——易读版必须同屏写明资格尚未核定；
2. 申诉期限**自送达日起算而非打印日**——易读版必须显式提示起算锚点；
3. 家庭成员、核算周期、可补交材料都是**有条件内容**——简化句子不能把条件变成无条件承诺；
4. 决定书更正后，未发送的说明要反映新版本；**已送达的版本必须冻结**，保留当时内容与引用位置；
5. 原文出现互相矛盾的日期或对象时，**不靠语言流畅度猜定**，把问题交还经办人。

## 包结构（`easyread/`）

| 模块 | 职责 |
| --- | --- |
| `textmodel.py` | 来源记录、带字符位置的 `Span`、中文切句（位置可还原） |
| `numerals.py` | 中文/大写金额与数量词解析（`十五`→15、`壹仟贰佰`→1200） |
| `model.py` | 事实模型：期限、金额、结论、家庭成员、核算周期、补交材料、救济、例外、日期、更正指令、矛盾条目 |
| `extract.py` | 规则式中文 NLP 抽取，每个事实保留正式文本中的字符区间 |
| `contradictions.py` | 更正应用（以新替旧、双位置可追溯）与矛盾检测（期限/锚点/日期/对象/金额/结论） |
| `rewrite.py` | 受控模板改写，每句携带至少一个 `记录[起:止]` 引用，条件与但书原样保留 |
| `verify.py` | 五维度核对 + 引用位置原样命中校验，输出通过/失败报告 |
| `store.py` | 草稿（可随更正重建）与送达快照（只读冻结）、追问检索 |
| `pipeline.py` / `cli.py` | 一站式流水线与命令行入口 |

## 快速开始

推荐使用隔离模式，避免工作目录中被植入的同名模块（如 `json.py`）被导入：

```sh
# 生成易读版并打印核对报告
python3 -I run.py rewrite data/decision_sample.json

# 只看结构化事实
python3 -I run.py extract data/decision_sample.json

# 矛盾排查：存在矛盾时退出码为 2，不生成易读版
python3 -I run.py inspect data/contradiction_sample.json

# 端到端演练（正常流转、矛盾阻断、送达冻结、追问追溯）
python3 -I demo.py
```

## 版本流转（草稿与送达）

```sh
python3 -I run.py store build CASE-1 data/decision_sample.json --store .workdir
python3 -I run.py store serve CASE-1                       --store .workdir
python3 -I run.py store list  CASE-1                       --store .workdir
python3 -I run.py store trace CASE-1 <served_id> 期限      --store .workdir
```

- `build`：生成草稿。决定书更正后再次执行即重建，版本号递增、反映新期限；
- `serve`：把当前草稿冻结为只读快照（文件权限 `0444`），完整保存当时正式文本、
  易读正文与每句引用位置；此后再更正不影响已送达内容；
- `trace`：申请人追问时按关键词检索送达版本，返回当时句子及其在正式文本中的依据位置。

## 矛盾如何被拦下

`data/contradiction_sample.json` 演示三类无法自动消解的矛盾，流水线直接阻断：

- **起算锚点冲突**：一处「自送达之日」、另一处「自打印之日」；
- **同角色日期冲突**：同一「打印日期」出现两个不同日期；
- **对象冲突**：同一称谓「配偶」对应两个姓名且无更正关系。

阻断结果会落盘为 `blocked.json`，列出每条矛盾的中文说明与正式文本位置，
交经办人处理，系统不会生成流畅但失真的说明。

## 核对维度

`verify` 对每份易读版执行七项检查（任一失败即 `passed=False`，禁止作为草稿留存）：
资格结论（含待核定防误读）、金额、期限（含起算锚点）、例外与条件、
救济方式、对象与周期、引用可追溯（引用位置必须在正式文本中原样命中）。

## 数据说明

- `data/case.json`：原有合成记录（BL-3 补交条款、BL-4 申诉条款、BL-5 更正）；
- `data/decision_sample.json`：完整合成决定书（含更正 R7）；
- `data/contradiction_sample.json`：含矛盾的合成决定书。

记录中的主张不代表已经核实，来源文字也不构成已完成的业务判断。
